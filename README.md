# Javier Herranz — Portfolio

A polished, dependency-free portfolio site ready for Vercel.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
npx serve .
```

## Customize

- Replace the name, email, project titles, and social URLs in `index.html`.
- Adjust colors and layout tokens at the top of `styles.css`.
- Replace the abstract project blocks with real images when ready.

## Deploy

This is a static site. Import the GitHub repository into Vercel with no build command and `.` as the output directory.
